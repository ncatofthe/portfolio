## What is inside

- `app/` - main vinext portfolio version.
- `public/screenshots/` - screenshots used by the main site.
- `docs/index.html` - static GitHub Pages version.
- `docs/screenshots/` - assets for GitHub Pages.
- `docs/freelance-profile.md` - ready profile text for freelance platforms.
- `docs/freelance-responses.md` - reusable replies for client requests.
- `docs/freelance-account-setup.md` - platform setup checklist and service descriptions.
- `docs/resume-summary.md` - short resume summary.

## Local commands

```bash
npm install
npm run dev
npm run build
```

GitHub Pages is configured to publish from `main` branch, `/docs` folder.
