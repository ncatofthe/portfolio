# Жихарев Глеб - профиль для фриланс-бирж

## Основное позиционирование

Разработчик внутренних сервисов, автоматизации и прикладных IT-инструментов. Помогаю компаниям и частным заказчикам закрывать понятные рабочие задачи: сайт, бот, скрипт, интеграция, админка, учет, ServiceDesk, простое приложение или техническая автоматизация.

У меня есть практический опыт системного администратора-программиста, поэтому я понимаю не только код, но и среду, где решение будет работать: Windows/Linux, рабочие места, сети, Windows Server, виртуальные машины, Bitrix, оборудование, накопители, диагностика и поддержка пользователей.

## Короткое описание для профиля

Разрабатываю сайты, ботов, скрипты, внутренние сервисы и простые приложения. Умею разобраться в задаче без идеального ТЗ, предложить понятный план, написать код, подключить API/базу данных, проверить результат и объяснить запуск. Дополнительно могу помочь с администрированием, Windows Server, Bitrix, виртуальными машинами, диагностикой ПК, дисками и серверным оборудованием.

## Примеры проектов

### Office ServiceDesk

Внутренний портал для обработки обращений сотрудников: заявки, статусы, роли, комментарии, вложения, база знаний, email-интеграция, администрирование и отчеты. ServiceDesk используют 3 компании.

### MarketplaceBot

Desktop-приложение и боты для автоматизации ответов на отзывы Ozon и Wildberries. Решение помогло компании и сократило ручную работу 3 сотрудникам.

### AI Workbench

Локальная offline-first платформа для многоагентной разработки: задачи, агенты, история запусков, локальные LLM через Ollama. Используется друзьями-фрилансерами и в реальных проектных задачах.

### SystemInfo

PowerShell-утилита для сбора информации о Windows-ПК без установки дополнительных программ. Полезна для диагностики и IT-поддержки.

### Inventory App

Приложение для учета IT-оборудования и быстрых инвентаризационных задач.

## Ограничения, которые лучше указать спокойно

- Не беру задачи на взлом, обход защит, кражу данных, спам или скрытое наблюдение.
- По восстановлению данных сначала провожу оценку ситуации; 100% результат заранее обещать нельзя.
- Для доступа к аккаунтам, серверам и административным панелям работаю только с разрешения владельца.
- Если задача требует лицензий, платных API или доступа к сервисам, это обсуждается отдельно.
