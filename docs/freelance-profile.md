# Жихарев Глеб - профиль для фриланс-бирж

## Короткое описание

Разрабатываю внутренние сервисы, автоматизацию, ботов, API-интеграции и служебные приложения для бизнеса. Могу разобраться в задаче без подробного ТЗ, предложить понятную структуру решения, написать код, подключить API, базу данных и довести проект до рабочего состояния.

Работаю с Python, JavaScript/TypeScript, React, PHP, REST API, MySQL, PostgreSQL, SQLite, Telegram/API-ботами, PowerShell и автоматизацией рабочих процессов.

## Что можно заказать

- сайт, лендинг, многостраничный сайт или адаптивную верстку;
- Telegram-бота или бота для обработки сообщений;
- скрипт для автоматизации повторяющихся действий;
- парсер, обработку файлов, таблиц или данных;
- desktop/web-приложение под внутреннюю задачу;
- интеграцию с API;
- CRM, ServiceDesk, админку, личный кабинет;
- автоматизацию маркетплейсов Ozon/Wildberries;
- вспомогательные инструменты для рабочих процессов;
- доработку существующего проекта.

## Как я работаю

1. Уточняю задачу и ожидаемый результат.
2. Предлагаю понятный план реализации.
3. Собираю MVP или первую рабочую версию.
4. Показываю результат, исправляю замечания.
5. Передаю проект и объясняю запуск/использование.

## Сильные стороны

- умею переводить бытовую или бизнес-проблему в техническое решение;
- не зациклен на одном стеке, выбираю инструмент под задачу;
- могу сделать frontend, backend, базу данных и простую инфраструктуру;
- имею опыт проектов, которые реально использовались компаниями;
- спокойно отношусь к задачам без идеального ТЗ.

## Примеры проектов

### Office ServiceDesk

Внутренний портал для обработки обращений сотрудников: заявки, статусы, роли, комментарии, вложения, база знаний, email-интеграция, администрирование и отчеты. Сейчас ServiceDesk используют 3 компании.

### MarketplaceBot

Бот и desktop-приложение для автоматических ответов на отзывы Ozon и Wildberries. Автоматизация маркетплейсов сократила объем ручной работы для трех сотрудников.

### AI Workbench

Локальный инструмент для многоагентной разработки с использованием Ollama и локальных LLM. Используется в реальных проектных задачах как помощник для планирования и ускорения разработки.

### SystemInfo

PowerShell-скрипт для сбора информации о Windows-компьютере без прав администратора. Подходит для диагностики и IT-поддержки.
